操作说明与快捷键
布置
点顶部右侧家具图标展开家具库，拖入画面。选中对象后，在右侧调整尺寸、位置和材质。场景显示与光照设置集中在画布右上角。
选中家具后，拖动顶部圆点旋转，拖动右下方块自由调整尺寸；左右中点调整宽度，下侧中点调整进深。2D 网格和尺寸在画布右上角面板设置，贴墙吸附默认开启，可在“视图”菜单调整。
墙体与洞口
“画墙”依次点击起点和终点。“门洞 / 窗洞”点击普通墙放置。选中洞口后可调整位置、净宽和门轴。
新增隔墙、洞口和测量线可以删除。删除新墙时一并移除该墙洞口；撤销时一起恢复。原有普通墙使用拆除 / 恢复，承重墙锁定。
快捷键
V / M / X选择 / 测量 / 拆墙Delete删除选中对象⌘ / Ctrl Z撤销⇧ ⌘ / Ctrl Z重做⌘ / Ctrl D复制家具R旋转家具 45°T / F切换 2D、3D / 适应[ / ]家具库 / 属性栏Esc取消绘制或选择W A S D / 方向键漫游移动E / Esc / 空格开关门 / 暂停 / 继续
浏览与切换
左侧第一项切换 2D / 3D，默认 2D；下方工具随视图变化，也可按 T 或使用“视图”菜单。画布右上角的功能面板随视图变化：2D 显示网格、尺寸，3D 显示视角、显示和光照操作。漫游直接开始：电脑和触屏均可使用左下摇杆，WASD / 方向键移动、拖动画面转头；Esc 暂停，空格或点击画面继续。可主动开启锁定鼠标，Esc 释放；锁定失败自动回到拖动操作。漫游隐藏侧栏，设置和帮助按需展开。“视图 → 浏览模式”禁止修改；点击“返回编辑”退出。
保存
右下角显示保存状态，编辑自动保存到当前浏览器。“文件 → 导出 HTML”生成可离线打开的单文件方案；JSON 用于备份与再次编辑。
