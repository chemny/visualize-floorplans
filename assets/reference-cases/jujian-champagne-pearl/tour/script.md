# 56 秒全屋导览

原生 2880 × 1620，24 fps。按玄关、公卫、次卧、阳台、客厅、主卧、主卫、书房、餐厨的顺序连续参观。中文讲解与背景音乐按镜头节奏混音。

| 时间 | 讲解 |
|---|---|
| 0.45–4.09 秒 | 从入户玄关开始，一起看看这个家的布局。 |
| 5.45–8.69 秒 | 外面是独立洗手台，往里走是公共卫生间。 |
| 11.10–15.41 秒 | 走进次卧，床铺靠墙布置，窗边引入自然光。 |
| 16.05–19.74 秒 | 穿过推拉门来到阳台，另一侧安排了洗衣区。 |
| 20.80–26.08 秒 | 回到客厅，沙发、茶几和电视墙，让起居空间更舒适。 |
| 29.15–32.46 秒 | 接着是主卧，床头和柜体延续柔和的浅色调。 |
| 34.05–36.31 秒 | 主卫用玻璃隔开淋浴区。 |
| 38.15–42.51 秒 | 再看书房，书架沿墙展开，书桌靠近窗边。 |
| 44.00–48.23 秒 | 最后来到餐厨区，餐桌与厨房相邻，动线紧凑。 |
| 49.60–53.38 秒 | 看完厨房，再回望客厅，这就是完整的全屋导览。 |
