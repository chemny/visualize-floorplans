# 56秒房主方案导览

面向房主，介绍主要陈列与定制功能。九个区域，连续实际H5模型漫游，视线高度1.6米，无切镜。

| 时间 | 空间 | 镜头重点 |
|---|---|---|
| 0.0–6.4秒 | 入户与洗手台 | 玄关、公区关系、外置洗手台 |
| 6.4–10.3秒 | 公卫 | 马桶、淋浴与干湿关系 |
| 10.3–16.6秒 | 次卧 | 床、衣柜、通往阳台的实际通道 |
| 16.6–21.6秒 | 阳台 | 左侧休闲、右侧洗衣柜 |
| 21.6–28.6秒 | 客餐厅 | 阳台返回后沿餐桌、厨房方向介绍空间关系，顺着主线转入主卧；沙发电视在入户时介绍 |
| 28.6–33.1秒 | 主卧 | 床、双层窗帘、定制梳妆台 |
| 33.1–37.9秒 | 主卫 | 台盆、马桶、淋浴 |
| 37.9–42.6秒 | 书房 | 定制书桌、书柜与多功能使用 |
| 42.6–47.2秒 | 餐厨转入 | 沿通道转入厨房，餐桌只作为路径背景 |
| 47.2–52.9秒 | 厨房 | 冰箱、台面、水槽、双灶 |
| 52.9–56.0秒 | 离场 | 清楚回到玄关和出口 |

右半边推拉门通行；客餐厅介绍后直接去主卧。全屋主灯开启，顶面修复偏色。旧版保留，新版已由用户确认。
