# Local beta status · 0.2.0-beta.3

Date: 2026-10-05. This is a local implementation and packaging closeout, not a
GitHub release or production certification.

## Completed implementation

- Reusable offline workbench template and editable source: architectural wall
  unions/openings, three drawing modes, 2D/3D synchronization, furniture sizing
  and layers, finish presets, installation heights, recessed lights and navigation.
- External case input: model dimensions, rooms, walls, furniture/fixtures,
  ceilings, labels, area source, entrance IDs, camera start and approval records.
  Current-case corrections are preserved in its external snapshot, not shared
  coordinate migrations. Case examples are not included in the distributable.
- H5 command entry: read-only doctor; build/export/prepare; actual-mesh camera
  audit; still/sample/full-frame capture; source-bound resume; optional FFmpeg
  encoding with probe; relative-link handoff and SHA-256 archive packaging.
- Unified production command defaults to H5; Blender remains an explicit optional
  importer of the same mesh stream. Existing conceptual-image planner and gates
  remain available; no new image/video provider is embedded.
- Documentation, agent metadata, dependency attribution, version and local
  installation archive.

## Verification boundary

This closeout checks Python/JavaScript syntax, entrypoint help, same-case HTML
construction, Skill metadata/structure, package hashes and ZIP integrity. A build
does not verify UI interaction, rendering fidelity, every camera clearance,
cross-platform portability or cross-floorplan behavior.

The accepted homeowner H5 walkthrough, white ceiling and enabled lights are
evidence for that recorded local case. The extracted generic engine has not been
given fresh end-to-end visual acceptance. An unchanged approved artifact remains
usable; a newly rebuilt template result must not inherit that acceptance.

## Fresh same-case verification · 2026-10-05

A new run used only the original dimensioned user plan and written requirements.
Historical generated images, video, model snapshots and camera routes were not
inputs. The source scan was interpreted and manually entered as a new case;
this does not certify fully automatic image recognition.

- 126 Python regressions and 26 browser interaction checks passed locally.
- Three drawings, actual mesh export, nine interior cameras, a bird view, nine
  fresh AI reference-image edits, full H5 frame capture/FFmpeg encoding and
  source-bound partial-capture resume were exercised. Seedance was excluded.
- Fixed low-sill window validation/mesh metadata, case-relative wall origins,
  browser export readiness, preview route authorization, trim false blockers,
  sliding leaf poses, wall-join padding, ordered visit binding and tight-corner
  frame resampling. Added five route regressions against the prior baseline.
- Hanging fixtures follow finished ceilings. The local audit now rejects a main
  luminous face hidden by ceiling geometry as well as an unlit fixture.

The functional chain is exercised; visual acceptance is still pending. A
separate arrival-frame subject probe found four planned subjects absent at the
scripted arrival frames. Camera gaze/time allocation needs that quality review;
collision-free output is insufficient. AI images can add details and change
framing/materials. Native generated images have rounded near-16:9 pixel sizes.
They are concept previews, not dimensional geometry or approved finished work.
Complex ceiling polygons were divided into simple zones in this test case;
other shapes and other floorplans remain unverified. macOS was the only platform
exercised. Optional Blender is not part of this H5 main-flow verification.

Local code and documents were updated; no commit, push or public release was
performed. A prior installation archive must not be described as containing
these later fixes without rebuilding and checking it.
