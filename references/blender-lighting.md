# Blender 分支的灯光约定

适用于 `run_production.py --engine blender --render-profile`、`blender-draft`、`blender-review-film`。灯光属于案例配置：具体瓦数、颜色、哪类灯是主灯都写在案例的灯光配置（render profile）里，不写进引擎。下列数值都是产品阈值和 1 号户型的调试结果，不是行业标准。

## 1. 灯光配置的键（`blender_lighting_profile.py` 校验，未知键直接报错）

| 键 | 作用 |
|---|---|
| `fixtureWattsPerIntensity` | 户型里每个灯具的“强度”换算成 Blender 瓦数的全局系数。不写就没有灯具光，画面会很暗 |
| `fixtureWattsByType` | 按灯具的家具类型（`pendant` 吊灯、`ceilinground` 吸顶圆灯、`lightpanel` 灯板、`downlight` 筒灯、`tablelamp` 台灯、`ledstrip` 灯带、`cabinetlight` 柜灯等）单独设系数 |
| `fixtureWattsById` | 按灯具编号单独设系数，优先级最高 |
| `worldStrength` / `worldColor` | 天空/环境光，同时照亮室内 |
| `cameraBackgroundStrength` / `cameraBackgroundColor` | 只影响镜头直接看到的背景（敞开的门窗外），不影响室内照明；不写颜色则用 `worldColor` |
| `spotFixturesAsCones` | 户型里的聚光灯（筒灯、射灯）按它的朝向和锥角做成 Blender 聚光灯。不开时所有灯具都是点光源，筒灯会把周围天花板照成一圈泛白光斑 | 
| `excludeFixtureHousingShadows` | 灯具外壳不投影，避免筒灯自己挡光 |
| `lights`、`materials` | 额外的人工灯和材质覆盖 |

瓦数 = 户型里灯具的强度 × 系数，系数取值顺序：灯具编号、类型、全局。

## 2. 怎么定一套灯光（顺序）

1. **先不配灯**渲 5 张代表帧，确认画面确实暗：只有天空光时偏暗是正常的。
2. 配全局系数，**三档对比**（例如 12、30、100）。过曝和发暗之间选，本案落在 12。
3. 分主灯和辅灯：主灯（吊灯、吸顶圆灯、灯板）适当加，辅灯（筒灯、台灯、灯带、柜灯）适当减；整体平均亮度会变化不大，变化主要在光斑和层次。本案 14 瓦主灯、4 瓦辅灯。
4. 用户点名要调的某类或某区域的灯，用 `fixtureWattsById` 单独调，不要拉动整体。本案客厅 8 盏筒灯降到 60%。
5. 每次调整都出**前后对比图**（同帧、同分辨率、上下排），并报平均亮度；对比图发给用户，由用户定。

6. **筒灯做成聚光灯是可选项，不是默认**：本案试过，聚光灯天花板光斑消失、全片亮度平均降约 7 到 10，但它会改变所有聚光灯具的观感，超出了“只调客厅筒灯”的范围，用户没有采用。用户只点名某一处灯时，只改那一处，其余保持用户已认可的版本，不要顺手改全局。

## 3. 亮度的参考范围

平均亮度（0 到 255，`blender_lighting_profile.brightness_report`）：140 到 170 之间为参考带，低于 140 偏暗，高于 170 偏亮发白。这只是评审参考。浅色、白墙为主的户型，装修展示片通常明亮，本案最后定在 166 到 180，偏亮但用户认可，**以用户判断为准**。只测一个户型，换户型要重新比。

## 4. 敞开的门窗外

室内看向敞开的入户门或窗时，门洞里是“镜头背景”，默认是蓝灰色，看起来像一块平板。用 `cameraBackgroundColor` 配成明亮的暖白（本案 [0.93, 0.91, 0.87]，强度 1.0），读起来像有日光的走廊。它仍是平的，不是室外的三维重建；需要真实视差时必须另做，不要冒充。

## 5. 不要做的事

- 不在引擎里写死房间名、灯具编号或瓦数。
- 不为了“看起来亮”而加大天空光去代替灯具。
- 不因为平均亮度在参考带内就宣布光线合格，必须出图给用户看。
- 灯光改了，已确认的静态样板失效，需要用户重新确认再放行动态短样和整片。
