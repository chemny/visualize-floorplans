# 同一路线、两种视频渲染方式

默认 `rendering.engine=h5`（标准渲染）；显式选择 `blender`（高质量渲染）。
不根据画面效果或本机软件存在与否自动切换引擎。使用已有工具，不自动安装。
观看网页/视频无需 Blender；仅执行 Blender 渲染的主机需要安装它。
MiniMax/ComfyUI 保留为独立可选生成式处理，不是任一分支的必经环节。

## 固定流程

顶部四页：参观路线 → 镜头预演 → 视频审阅 → 讲解成片。
路线和预演共用。视频审阅绑定所选引擎输出的具体静音视频。
两种方式都必须通过原有明确视频批准，才能 narration-prepare/compose。
更换视频使旧视频批准失效；原路线字节未变时不必重新规划。

## 可执行入口与当前边界

`h5.py render-prepare --job RENDER_JOB --out NEW_DIRECTORY`
读取 `assets/h5/tour/render-job-template.json`。绑定实际 bundle、tour、runtime、
routeReview，并执行既有路线批准检查。只写制作计划和原路线副本；不渲染、不授权。
默认标准分支继续使用已有 H5 捕获入口、原预演与捕获检查。
Blender 分支输出代表帧的同源静态命令；`run_production.py --engine blender`
现在必须传 `--route`，直接读取这份逐帧路线，禁止调用路径规划。
`--runtime` 使用同源实际网格，`--render-profile` 指向案例配置。
静态命令并不代表样板已确认。多机位采样后须补门洞、卫浴、窗景等困难位置。

Blender 无约束动画入口仍关闭，不能仅删除禁用开关。制作从
`static_samples_then_dynamic_validation` 开始；具备下文证据及明确整片授权后，进入独立的完整静音审阅入口。
短样、整片和远程预检均必须绑定routeReview、routeScene、routeGeometry，并执行与H5一致的原路线批准及源数据检查。已接通的短样入口见下文；整片放行仍须：已确认静态样板绑定 → 相同逐帧相机的动态短样 →
投影/门洞遮挡/材质阴影闪烁/降噪跳变/窗景视差/耗时检查 → 短样审阅 → 全片。
静态背景板不具备移动视差，不能直接拿当前单机位窗景制作全屋动画。
不可用时明确报告，保留 H5 可用，不自动降级冒充 Blender 输出。

灯光配置、主辅灯分档和对比图流程见 [Blender 灯光约定](blender-lighting.md)；整片耗时和提速取舍见 [Blender 提速](blender-render-speed.md)。

## 静态质量流程

冻结来源和可改范围 → 检查贴图、色彩空间、纹理尺度与节点映射截断 →
局部材质/低分辨率灯光对照 → 目标改善可见且无新瑕疵 → 高清图 → 用户确认。
同一问题两轮无实质收益则重新诊断，不继续盲调。
同条件对照统一机位、尺寸、采样、降噪和随机种子。日景由穿窗日照塑形，
补光维持暗部可读，检查亮斑丢纹理、填平阴影、背景拉伸与发白。
这些不是固定光源参数。几何、材质、相机的变更范围分别核对。

所有具体灯光、配色、织纹尺度和确认图留在案例配置。静态确认不推导全屋/动画批准，
不把候选图或测试通过当成用户确认；公共规范不保存某个案例的当前进度。

## 动态短样入口

`h5.py blender-draft --job JOB --out NEW --blender EXISTING_BLENDER --ffmpeg EXISTING_FFMPEG`

任务 schema=`homeowner-blender-draft-job/1`，绑定 scene/tour/bundle/staticApproval/
authorization 的实际路径和 SHA-256。静态批准绑定具体场景与图片；短样授权必须为
`scope=blender_dynamic_draft`、明确用户证据及完全相同的起止帧与静态锚点。静态锚点可以位于短样区间之外，但必须与已确认场景对应，不能为截取另一房间而擅自移动样板机位。每次最多5秒，
不允许整个路线，不自动生成声音。依赖只检测，不安装。
相机直接应用原路线每一帧，不插值、不重算路径；核对方案、原始模型尺寸、
静态锚点和相机投影，并记录室内几何指纹及逐帧近表面遮挡诊断。
固定随机种子、降噪与光照。新任务用绑定的 executionProfile 明确选择后端及CPU回退政策，
不停止其他服务；旧任务的兼容回退仍须记录实际设备。远程执行、OptiX/Vulkan与最终
检查见 [执行与交付 SOP](production-execution-and-delivery.md)。
若使用单张概念背景，只允许作为明确标注的远处平面示意；沿锚点射线移远以保留
静态构图，记录锚点投影误差。这不是室外三维重建，整片仍需处理视差和背景覆盖。
`blender_draft_review.py` 提供光流补偿后的亮度跳变诊断，不替代实际连续播放。
输出准确帧数/帧率短片、来源及捕获报告；所有视觉状态默认为 pending。
短样本身不能授予整片动画批准或绕过视频到讲解的确认关卡。

多位置验证使用 `blender_draft_review.validation_index` 与共享模板，汇总门洞、不同卫浴和实际平移窗景短样。所有片段须同源场景和路线，逐段保存检查结果与待用户审阅状态；某段通过不能替代其他段，采样验证也不能自动放行整片。

## 分房间照明修正

动态短样可显式绑定 `roomPresentation`（`blender-room-presentation/1`），并将同一配置的哈希写入短样授权。它是待审修订，不是新静态效果已确认。
现有局部点光源只改输出、颜色与柔和半径；新增窗景卡共享原有环境材质，明确相机/透射/反射可见性，不改室内家具、墙体或材质节点。所有修正一次性加载，禁止逐帧切灯。
照明输出值与窗景坐标留在案例配置。先做各目标房间静态小样，并在相同渲染条件下对照受保护房间，确认局部修正没有显著改变已确认效果，再重制原区间短样。补亮还须检查发白、洁具细节与镜面；直接窗景和镜面可见窗景应一起核对。

窗景卡如有 `windowMesh` 与 `coverageFrames`，在捕获前按真实窗网格边界与该区间每帧相机做投影覆盖检查；不完整则停止捕获。禁止只用一个静态机位判定动态背景够大。背景、灯光、材质及确认机位的保护检查分别记录，补亮不能代替反射和视差检查。

## 完整静音审阅片（独立授权入口）

`h5.py blender-review-film --job JOB --out NEW --blender EXISTING --ffmpeg EXISTING`

使用 `homeowner-blender-review-job/1`，授权 scope=`blender_review_film`；原限长短样入口仍不能捕获整条路线。
完整作业绑定已确认静态场景、原 bundle、原逐帧路线、静态批准，以及相同来源的门洞、卫浴、窗景移动真实短样结果。
短样结果须绑定实际视频，近表面及全局闪烁诊断无未解决项。照明修订须另绑定全屋代表机位校准图、同一 roomPresentation 和原路线；工程复核不伪造用户验收。
必须有用户明确要求渲染整片的证据，且授权覆盖精确完整起止帧；输入或配置哈希变化即失效。

每帧直接应用原路线位置、朝向、视场角和移轴；不插帧、不改时长。全片一次性加载固定灯光、曝光、窗景和材质，禁止按房间镜头切灯。
可使用固定远景封闭环境，核对六面封闭且全部源几何/相机在内；沿原机位保留已确认窗景投影。概念窗景仍须明确非实测室外重建。
渲染记录逐帧图像哈希、相机投影、室内几何指纹；相同绑定作业可断点恢复。渲染实现、模型、路线和照明配置均不得中途更换；完整帧序、帧率和时长须编码后复核。
最多两个独立捕获进程仅分配不同源帧，合并时拒绝漏帧、重复帧或设置不一致；不以并行任务改变相机和时间轴。实际画质、资源占用和耗时仍需测量。

结果是 `homeowner-blender-review-result/1`，purpose=`video_review`、visualReview=`pending`、narrationAuthorized=`false`。
共享四页模板第三页展示 Blender 渲染审阅视频，第四页保持待生成；只有用户明确确认这个具体整片，才能配音、字幕和音乐合成。
回归覆盖整片/短样授权隔离、缺失或篡改证据、错误完整帧区间、照明配置变化、原视频确认关卡，以及真实封闭窗景覆盖反例。

窗景投影须同时检查几何覆盖和贴图坐标覆盖：UV 超出图片范围时禁止直接延展边缘像素。水平重复必须显式声明连续映射，竖向越界需做天空/地面颜色过渡，并检查原有材质未被改写。采用外景材质副本，保持室内材质和已确认机位的原图投影；实际检查包括斜视窗口、门口透视和镜中窗景，不能仅凭正视校准图放行。

## 动画局部稳定性与采样诊断

单帧样板通过不表示低采样动画通过。短样与整片分别记录实际采样、是否自适应、最低样本、降噪器/辅助通道、随机种子和光照配置；不在整片时未经验证降低质量档。固定随机种子也不能保证移动中没有局部闪烁。

`blender-draft` 和完整审阅作业可绑定 `qualityProfile`（`blender-render-quality/1`）；相同哈希必须进入该作业授权。支持显式固定/自适应采样、最低样本与阈值，以及独立焦散诊断开关。不同质量候选复用同一条原路线、相同分辨率/灯光/材质，先单变量比较，再选择满足实测稳定性的档位；不把某案例的64/128次当通用合格线。

`retainDiagnosticPasses=true` 留存同次渲染的降噪前画面、降噪后画面，以及实际EXR颜色、法线、直接/间接漫反射、反射与透射通道。验证命名通道真实连通和文件存在；不能以空文件或代码字段代表已导出。当前短样按精确逐帧相机捕获，不把没有有效前后相机运动的Vector通道宣称为跨帧降噪输入。Blender接口需实际小样检查，不能把“批量降噪”命令名当成已验证的时域算法。

全局平均/中位亮度诊断只检测全屏跳变，不足以验收家具、柜门、地板、玻璃与镜面的局部闪烁。复核可跟踪同一几何表面的世界坐标区域，剔除遮挡和出画，不把真实高光移动直接算成闪烁；实际连续播放仍必须单独检查。局部不稳定时先比较原始和降噪结果，再针对采样、降噪、反射/焦散或几何冲突修正，不能用改变已确认光线或涂抹整片来掩盖。
