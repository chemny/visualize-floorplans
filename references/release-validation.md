Current Skill and shared H5 engine identity: **0.2.1**. Codex/macOS executes the
Python and Node regression suite. Windows receives static path, UTF-8, subprocess
and browser-file review, not Windows runtime certification. Claude Code and
OpenClaw discovery and host image integrations remain untested. The owner

# Beta release validation · 0.2.0-beta.3

Checked on 2026-10-06. This is a bounded same-case and packaging report, not a
cross-floorplan certification. At that historical checkpoint, private plans and media were excluded. The current release includes the provider-authorized curated reference case, documented in `assets/reference-cases/jujian-champagne-pearl/README.md`.

## Executed checks

- 155 Python regressions, including invalid/stale review, source binding,
  route clearance, cue timing and Chinese JSON/path handling.
- Eight focused Node subject-window checks: duration, flicker, tiny subjects,
  close walls, stale revision, missing objects, sampling and all-object coverage.
- Source compilation reproduces the bundled H5 engine byte for byte using the
  existing maintenance dependencies; normal users need no esbuild installation.
- Clean-directory source installation: read-only environment discovery,
  regression suite, subject tests and actual same-case standalone H5 build.
- Same-case actual model: eleven observation chapters, two Hz sampling, each
  declared subject readable for at least two continuous seconds, no relaxed
  visibility policy. Actual mesh clearance, fixture emission and luminous-face
  visibility gates pass. The radius remains a camera-envelope approximation,
  not certified human passage or a construction requirement.
- A case-local source record has current original/drawing hashes, independent
  scan-axis anchors and explicit derived versus designed geometry provenance.
- Two public-space AI outputs were compared with their exact actual H5 cameras;
  original generated/reference hashes verified a legacy metadata migration.
  Other generated views are not certified by that two-image review.
- Newly generated case outputs retain pending human acceptance. Passing numeric
  checks cannot publish an accepted-delivery label; unchanged approved case
  artifacts remain preserved separately.

## Static portability review

Reviewed production Python path handling, UTF-8 JSON reads/writes, argument-list
subprocess calls, executable/module discovery, Node file URLs and HTTP serving,
and Windows font discovery. Chinese and space-containing paths were exercised
on macOS with default-encoding warnings treated as errors. No installation uses
private directories or copied browser profiles. The optional macOS Blender
application fallback is guarded by the OS check; explicit executables also work.

Windows was not executed on a Windows host. Playwright/Chromium, FFmpeg and fonts
must already be available or installed through a separately authorized flow.
Codex/macOS was exercised; Claude Code and OpenClaw host discovery and image-tool
integration were not executed. Static review is not runtime certification.
